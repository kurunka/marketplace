# Как опубликовать и отправить отклик

> **Статус: опубликовано.** Репозиторий — https://github.com/kurunka/marketplace,
> CI зелёный. Шаги 1–5 ниже уже выполнены; оставлен как справка — пригодится,
> если понадобится пересоздать репозиторий или запушить правки с нуля.
> **Дальше сразу к шагу 6 — отправить отклик.**

Пошагово, с командами. Ничего не нужно делать «на глаз».

---

## Шаг 1. Установить Git

Без него репозиторий не создать. Вариант через winget (PowerShell от имени администратора):

```powershell
winget install --id Git.Git -e --source winget
```

После установки **закрыть и открыть PowerShell заново**, затем проверить:

```powershell
git --version
```

Если winget недоступен — скачать установщик с https://git-scm.com/download/win
и прожать «Далее» во всех окнах (настройки по умолчанию подходят).

---

## Шаг 2. Представиться Git'у (один раз)

```powershell
git config --global user.name "Ваше Имя"
git config --global user.email "почта@из-github"
```

Почта должна совпадать с той, на которую зарегистрирован GitHub, иначе коммиты
не привяжутся к профилю.

---

## Шаг 3. Создать репозиторий на GitHub

1. Открыть https://github.com/new
2. **Repository name:** `marketplace`
3. **Public** (обязательно — иначе клиент не откроет ссылку)
4. **НЕ** ставить галочки «Add README», «Add .gitignore», «Choose a license» —
   всё это уже есть в проекте, иначе будет конфликт при первом пуше
5. Create repository

---

## Шаг 4. Закоммитить и запушить

В PowerShell:

```powershell
cd "C:\Users\lepis\OneDrive\Документы\Проект по умолчанию\marketplace"

git init
git add .
git commit -m "Мини-маркетплейс: Nuxt 3 + FastAPI + PostgreSQL + Docker + CI"

git branch -M main
git remote add origin https://github.com/ВАШ_НИК/marketplace.git
git push -u origin main
```

При первом `push` Git попросит войти — откроется браузер, авторизуйтесь в GitHub.

**Проверить, что ничего лишнего не попало в коммит:**

```powershell
git status
git ls-files | Select-String -Pattern "venv|node_modules|sqlite|\.env$"
```

Последняя команда должна **ничего не вывести**. Если вывела — значит `.gitignore`
не сработал, файлы надо убрать из индекса:

```powershell
git rm -r --cached .venv frontend/node_modules
git commit -m "Убрать артефакты из репозитория"
```

## Шаг 5. Проверить ссылку как чужой человек

1. Открыть ссылку в **приватном окне** (Ctrl+Shift+N) — без входа в GitHub.
2. Убедиться, что:
   - README виден и картинки загрузились;
   - папки `backend/`, `frontend/` открываются;
   - нет `node_modules` и `.venv`.
3. Вкладка **Actions** — CI запустится автоматически. Если он красный,
   лучше починить до отправки: клиенты смотрят на бейдж.

Добавить бейдж CI в README (после первого прогона):

```markdown
![CI](https://github.com/ВАШ_НИК/marketplace/actions/workflows/ci.yml/badge.svg)
```

## Шаг 6. Отправить отклик

Текст: `freelance/отклики/маркетплейс-мини-kwork.md`

Перед отправкой заменить в тексте `[ссылка на репозиторий]` на реальный URL:

```
https://github.com/ВАШ_НИК/marketplace
```

Правила Kwork, которые влияют на результат:

- **Внешние ссылки в тексте отклика иногда режутся модерацией.** Если ссылка
  не прошла — писать «github: ваш_ник, репозиторий marketplace» и приложить
  скриншот README.
- **Отвечать в первые 30 минут** после появления заказа. Позже заказ обычно уже отдан.
- **Не отправлять один и тот же текст в 10 заказов** — Kwork это видит, и клиент
  видит по первой строке.

## Что говорить, если попросят показать работу вживую

Проект запускается одной командой на машине с Docker:

```powershell
cd marketplace
copy .env.example .env
docker compose up --build
```

Дальше — `http://localhost`. Это можно показать на созвоне за 2 минуты.

**Публичного демо-стенда нет.** Если клиент просит «дайте ссылку, где потрогать» —
два варианта:
1. Честно: «разверну демо на своём сервере, если дойдём до тестового задания»;
2. Поднять на бесплатном хостинге (Railway / Fly.io) — но это отдельная работа
   на 1–2 часа, и делать её имеет смысл только под конкретный заказ.

## Если отклик не сработал

Это нормально: на Kwork 15–30 откликов на заказ. Что делать:

1. Не менять текст десять раз — менять **первую строку** (её читают).
2. Публиковать не только отклики, но и **свой кворк**:
   «Сделаю маркетплейс или интернет-магазин на Nuxt + FastAPI» — 60 000–90 000 ₽.
   Тогда клиенты приходят сами, а не наоборот.
3. Первый заказ брать дешевле рынка — цель не деньги, а **отзыв**.
